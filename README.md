## Layout

Content is positioned inside a safe zone that clears the NCURA Regional Meeting '26 mountain banner along the bottom of the content background:

| Property | Value |
|----------|-------|
| Safe zone top | 102 px |
| Safe zone bottom | 350 px |
| Slide canvas | 1920 × 1080 px |

The center mountain peak reaches ~342 px from the bottom (y ≈ 738), so the safe zone ends at y = 730. With no logo at the top, the zone sits 50 px higher than the Annual Meeting layout while keeping the same 628 px height. Full-width graphic slides use fixed image heights that extend past the safe zone over the mountains, stopping above the NCURA banner text.

The title slide (`.title-safe`) places white text over the mountains, inside the template's title box (y = 740 to 1040).

## Customization

**To add or edit slide content**, open `index.html`. Each slide is a `<div class="slide ...">` block. Any element with `data-step` starts hidden and is revealed one at a time with Space/→ before the deck advances to the next slide. Use this for bullet list items (`<li data-step>`) and process-flow nodes.

**Presenters** appear on slide 2 and the contact slide (36) in a three-column grid: Nathan Wiggins (`wiggins.jpg`), Bert Baumgaertner (`Bert.webp`), and Lucas Marshall (`marshall.jpeg`), rendered as `<img class="photo-circle" style="object-fit:cover;" />` (`contact-avatar` on the contact slide). To swap in a different photo, replace the file in the repo root or the `src` on the corresponding img in `index.html`. Without a photo, a `<div class="photo-circle">AB</div>` shows initials on a blue gradient.

**Training vs. Inference (slide 11)** is drawn with inline SVG and CSS animations (`.ti-*` styles). The neural networks, training data stream, and GPU chips are generated by `buildTrainInfer()` in the script so both panels share the same network layout. Training loops every 4 s; inference cycles through three inputs at 5.4 s each. In print/PDF the animations freeze on a representative frame.

**How AI Writes (slide 12)** is an interactive next-word demo (`.nt-*` styles, `nextWordDemo()` in the script). The candidate words and their illustrative probabilities live in the `NT` table: each state lists `[word, probability %, next state]`, and every path ends when "." leads to the `end` state. Edit that table to change the sentence or its branches; keep each state's probabilities summing to 100.

**Section III slides (26–33)** share a `.callout` bar for each slide's closing point. It is blue by default; set `--cc` (accent) and `--cb` (background) inline for the amber, red, or green variants. Risk-level colors come from the `.lv-green` / `.lv-amber` / `.lv-orange` / `.lv-red` / `.lv-dark` classes, which only set `--lc` / `--lb`. They color the classification ladders (`.lv`), the case-study chips (`.flow-chip`), and the rows on the "One File" slide (`.mix-row`). Each of those rows tints when its tag is revealed, via `:has(.step-visible)`. The classify cards' badges are pinned to the top-right corner, so classifying a card doesn't change the layout.

**AI4RA External Evaluation (slide 35)** shows `evaluation_survey.png`, copied from `docs/img/` in [ui-insight/REACHWorkshop2026](https://github.com/ui-insight/REACHWorkshop2026). The QR code and the printed short link (bit.ly/3NwQpTi) both open the AI4RA survey at surveymonkey.com/r/AI4RAgeneral. The 260 px PNG is scaled up with `image-rendering: pixelated` so it stays scannable. If the survey link changes, replace the PNG and update the short link in the slide.

**Fonts:** Arial throughout. No external font dependencies.

**Images:** Both background PNGs (`Title_Slide.png`, `Slide_Template.png`) are referenced from the repository root. On the `regional` branch they are the NCURA Regional Meeting '26 backgrounds from the regional PowerPoint template (1672 × 941 source, scaled to fill the 1920 × 1080 canvas).
